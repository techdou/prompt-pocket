# 升级验收标准

- 保存/改名失败后原稿仍可读取；同分类/跨分类改标题成功后内容和分类正确。
- 手动删除可从恢复入口还原；覆盖前版本可查看/恢复；恢复失败不删除备份，不覆盖未确认的不同文件。
- 不完整远程清单与失败下载不清理本地；等字节长度不同内容被识别；排序元数据两个方向都可传递；多设备冲突保留可恢复内容。
- 快速切换提示词时旧请求不能覆盖当前正文；加载未就绪不可复制；未保存编辑不会因选中/刷新/关闭编辑悄悄丢失。
- 搜索覆盖正文，多关键词 AND；标题精确匹配优先；显示安全转义的命中片段；收藏/最近使用可筛选并在重启后保留。
- 变量解析支持中文名、默认值、重复字段、多行输入；缺少必填值不可调用；生成结果不修改模板文件；无变量沿用直接调用。
- 紧凑和整理模式可切换；键盘选中项自动可见；输入法回车不触发复制；全局快捷键失败时保留旧设置且给出明确反馈。
- 中英文所有新增界面有对应文本；恢复、模板、设置弹窗有键盘退出和焦点回归；小窗口不遮挡主要操作。
- `npm test`、`npm run check`、`npm run build`、`cargo test`、`cargo clippy --all-targets -- -D warnings` 通过；无法执行的平台项逐项记录实际原因。
- 浏览器预览与截图检查覆盖紧凑/整理、搜索、模板和设置，检查结果保存在 `verification.md`，截图保存在 `../screenshots/upgrade/`。
